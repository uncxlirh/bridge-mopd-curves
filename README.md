先看数学、代码、医学、法律、金融、指令遵循的正式评测，再看六领域均分。指令遵循取 IFBench 和 IFEval 平均，两个细项另行保留。表格按同一检查点列分数；缺失项显示 —，不按零分处理。正式评测按 40、100 步独立比较，使用原始分数表和柱状图，不在两个检查点之间连线。训练诊断曲线横轴仍是原始训练步数。

`critic/score/mean` 不是六领域准确率。这套奖励记录中其他训练领域是零分占位，因此它只支持重建数学训练题正确率。该曲线放在训练诊断区，不能用它判断其他领域或最终评测输赢。不同教师目标下的 loss 也只用于诊断。

只上传正式学生实验的训练曲线及已完成检查点评测。教师训练、冒烟测试、工程测试、校准、旧 bug 实验及独立静态测试不上传；正式学生实验只有一个检查点的评测仍保留。目前 15 条学生实验记录；六组 1.7B 主实验均已训练并正式评测到 100 步。W&B Finished 表示本次补传结束，实际进度看总览表。

使用官方 W&B Reports / Workspaces，没有自制展示界面。GitHub Actions 使用仓库加密 Secret `WANDB_BACKFILL_API_KEY`；密钥不写进代码和日志。更新 data 后自动补传，也可手动运行 `upload-wandb.yml`；仅调整视图可运行 `publish-wandb-views.yml`。`verify-wandb-overview.yml` 不带密钥，核对匿名访问、六领域图和实际分数。

新增的恢复率使用 `data/recovery_reference.json` 固定端点：`100 × (学生分 − 起点分)/(教师分 − 起点分)`，IF 两项先平均原始分。六域恢复率的均值、最小值与原始六域均分并列展示。恢复率允许负值和超过 100；原始均分仍保留，不能通过切换指标宣称小幅提升已获证实。完整分析见 `data/analysis.json`。

本轮 1.7B 评测主要只有 40、100 步两个检查点，因此主图为独立检查点柱状图。没有据此报告精确加速倍数或完整 AULC。教师曲线显示本步实际使用的 `used_lam`，以免把控制器下一步状态误当成本步教师。DN 乘子和回答长度等放在折叠的诊断区。

领域增益图统一减去同检查点的普通 MOPD（无 DN），六领域使用相同的对称差值刻度，正负号表示涨跌。另设同 DN 配方的对照，基线为普通＋DN。柱状图读取从真实评测计算的检查点 summary；不创建新实验，不填补中间分数。

展示按 MiMo RL 的分工组织：总览固定展示学生 loss、梯度、回答长度、截断率；正式评测单独展示；按领域的蒸馏信号、教师档位与 DN 乘子在工作区分组查看。学生训练设置、六组配方差别、采样与优化参数、定标规则和恢复记录保留在报告中。教师预训练过程不在本页范围内。整理版面时保留训练内容，通过分区和折叠降低拥挤。
